# PERT_VC — Monitoreo de puentes (Caso 6)

App React/Vite para planificar el proyecto **Sistema de Monitoreo y Gestión de Mantenimiento de Puentes Municipales** (Región del Biobío).

## Proyecto
- **Caso 6** — Monitoreo de infraestructura crítica
- **Asignatura:** GPY1102 Gestión de Proyectos de Software
- **Método:** Ágil Scrum (PO · Scrum Master · Development Team)
- **Alcance:** 2 puentes · vibración · inclinación · inspección visual
- **Presupuesto:** $50M–$100M CLP · **Plazo:** ≤ 12 meses

## App (`nuevopert/`)
```bash
cd nuevopert
npm install
npm run dev
```

Incluye: Documento central, EDT, PERT/CPM, Gantt, flujo de caja, matriz de decisión.
